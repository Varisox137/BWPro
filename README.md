# BWPro

受《阴阳师：百闻牌》启发的数字化卡牌对战游戏。长期目标为双人联机对战与图形客户端。

当前进度：Phase 1（规则引擎 + 正式数据 + CLI 热座 + 卡组构筑）与 Phase 2（FastAPI/WebSocket 联机对战）已完成。
正式数据：59 式神 524 卡（另 10 个召唤物/变形物/替换物/占位实体，含协战牌），经典/不夜之火/月夜幻响/沧海刀鸣四包完结，
平衡性数据录入至 20201224；吉运缘结包骨架已登记。测试 1229 个，按机制/主题归组。

## 快速开始

```bash
uv sync                              # 安装依赖
uv run python -m client.cli          # 主菜单：热座对战 / 卡组构筑 / 联机对战
uv run python -m server.main         # 联机服务端（默认 127.0.0.1:1037）
uv run python -m client.net          # 联机客户端（创建/加入房间）
uv run python -m db.validate         # 校验卡牌数据库
uv run python -m db.scaffold -h      # 式神/卡牌 yaml 脚手架（生成骨架再补效果块）
uv run pytest -q tests/              # 运行全部测试
```

## 项目结构

- `core/` — 规则层：状态模型、引擎、动作原语、事件、目标解析、对局组装、调试指令
- `db/` — 卡牌数据库（YAML 按 `db/<版本包>_<拼音>/<包内编号>_<式神拼音>/` 分目录，
  式神与其全部卡牌同目录，见 `db/packs.py`）、schema、组卡校验（天梯规则，可参数化）、卡组码
- `client/` — CLI 客户端：`cli.py` 热座 + 卡组构筑；`net.py` 联机（同一 `cmd dict` 协议）；
  `tui.py` TUI 基座（prompt_toolkit 底部输入框 + 常驻状态行，非 TTY 自动回退内置 input）
- `server/` — authoritative 联机服务端（FastAPI + WebSocket，详见 `server/README.md`）
- `diy/` — 自定义卡牌 DSL（Phase 3） · `docs/` — 规则与术语文档 · `tests/` — 测试

## 已实现机制

- 引擎管线：指令校验 → 动作 → 事件 → 触发队列 → 效果块结算；状态纯数据可序列化；
  完整伤害时点批次管线、结算中交互选择（断线续答/超时随机作答）、
  ext 键登记与效果键白名单等工程护栏（见 `core/registry.py`）
- 核心规则：抽牌/伤害/治疗/护甲/召唤/形态结附与消灭/升级/出击/完整战斗流程、
  气绝/复活/倒计时系统、增强装配管线、响应插入使用、协战牌（双归属、子选项打出）
- 关键字：连击/先攻/贯通/穿刺/远程/不屈/迅捷/屏障/追猎/直击/帷幕/必杀/暴击/运势/眩晕/庇护等
- 版本机制：能量与[充能]/爆能、[移动]、鼓舞（不夜之火包）；幻境队列与耐久（月夜幻响包）；
  灵咒与牌库灵咒、形态切换、气绝倒计时转化、符咒子类型（沧海刀鸣包）
- 多版本平衡性：式神/卡牌按日期快照留存全部历史版本，构筑与对局可按环境
  （别名或 8/6 位日期，见 `db/envs.py`）解析当时数据
- 卡组构筑：交互式编辑、天梯规则校验（4 式神 / ≤2 派系 / 各恰好 8 张 / 同名 ≤2）、
  卡组码导出导入、本地卡组文件（`~/.bwpro/decks.json`）槽位管理与战前选卡
- 联机对战：房间创建/按房码加入、准备流程、随机先手、调度 30s/回合 120s 计时、
  token 断线重连、状态按视角脱敏（详见 `server/README.md`）
- CLI 显示：座次配色、手牌数值实时求值、结算明细按时间线播放（0.3s/条）、
  TTY 底部输入框 + 常驻状态行
- 桌面 GUI：`python -m client.gui`（PySide6，`client/gui/`）——卡组构筑全管理、
  本地热坐与联机对战完整图形化（QGraphicsScene 场况、中央调度、拖拽出击/用牌、升级勾玉、先后手/回合开始动画、已展示手牌、结算播放、断线重连）、
  浅深双主题、项目 `library/` 美术配置合成与内容寻址缓存，对局式神使用 BWPDIY `render_entity` 小卡；
  式神录支持版本包/派系/全名筛选、单式主页、五卡分页与单卡详情；
  `library/` 中由 BWPDIY 编辑器生成的人工卡图/头像配置与图片随项目提交，供 GUI 直接复用；
  与 CLI 共享 `core/`+`db/`+`client/` 数据层和 `~/.bwpro/decks.json`

## 主要协议

玩家指令为 `cmd dict`，热座 CLI 与联机客户端共用：

```json
{ "op": "play_card", "uid": 1, "target": { "player": 1, "shikigami": 0 } }
{ "op": "assault", "index": 0 }
{ "op": "upgrade", "index": 2 }
{ "op": "choose", "uid": 42 }
{ "op": "end_turn" }
```

- 对局阶段：`mulligan` → `upgrade`（每回合开始）→ `battle`（主要阶段）
- `choose` 仅在结算中交互选择（pending_choice，如牌库顶检视）挂起时可用，uid 为选项卡牌实例
- CLI 序号显示与输入为 1-based，协议层保持 0-based index
