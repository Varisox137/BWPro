# GUI 设计文档（调研结论 + 界面初稿）

> 前置阅读：`docs/gui-plan.md`（技术选型：PySide6 桌面客户端，暂不开工）。
> 界面初稿图在 `docs/gui-mock/`（`generate.py` 生成，PIL 绘制，仅为布局示意）。

## 1. bwpemu 调研结论（github.com/menghuanmus/bwpemu，v0.7.6）

**定位差异**：bwpemu 是纯手动沙盒模拟器——抽牌、鬼火增减、生命变动全靠玩家手动按钮，没有规则引擎。BWPro 是权威引擎路线（服务端结算、客户端只渲染+发指令），二者游戏逻辑层无可借鉴之处。

**技术形态**：纯静态单页（vanilla JS + GSAP + socket.io CDN），GitHub Pages 部署前端 + 独立 socket.io 后端，无构建步骤。与我们 `server/webgui.py` + `static/webgui/` 的思路一致。

**可借鉴的 UX 模式**（后续 webgui/桌面 GUI 均可参考）：

- 大厅房间列表（免房码直接点入）、房间密码、复制房码按钮
- 观战模式、断线重连回房间
- 长按/悬停卡牌出 tooltip 大图与效果文本
- 骰子、卡牌飞行、眩晕等轻量特效（GSAP 补间即可，不必上游戏引擎）
- 结算记录 undo（仅沙盒有意义；我们引擎是权威结算，不做）
- 单人练习模式（对我们的价值：热坐已覆盖，优先级低）
- 移动端适配（media query 缩放布局；我们桌面优先，后期再说）
- DIY 卡库：容量上限、对局自动同步、选择性导入导出——与我们 Phase 3 + BWPDIY 联动时的参考

## 2. BWPDIY 卡图渲染工具接入方案（D:/Programming/BWPDIY，v1.5.0）

**架构红线（对方仓库明示）**：BWPro 只 `import bwpdiy.render`，不拖 FastAPI/web 层。其卡牌 yaml 引擎段已与 BWPro 口径对齐（协战 `shikigami1/2`），属互操作设计；其 M4（HTTP API + BWPro 集成文档）未做。

接入点（按优先级）：

1. **`client/gui/cardart.py`（桌面 GUI，首选）**：懒加载可选导入 `bwpdiy.render`，按卡牌 id 渲染卡面 PNG，缓存到 `~/.bwpro/cardart/`；导入失败或渲染异常时回退为文字卡面（即现在 mock 的样式）。作为 optional extra，不做硬依赖。
2. **Phase 3 DIY 联动**：BWPro `diy/` 只读消费 BWPDIY `library/<项目>/` 下的式神/卡牌 yaml——"BWPDIY 做卡、BWPro 打牌"。映射层（BWPDIY yaml → BWPro yaml 口径）只放在 `diy/` 一处。
3. **server webgui**：后期如需卡图，走同一 render 模块在服务端预渲染到 `static/`，不在浏览器端合成。

耦合护栏：单向依赖（BWPro → BWPDIY render），映射层单点，资产路径可配置，渲染失败永远可回退文字卡。

## 3. 界面初稿（docs/gui-mock/，1600×900）

布局参照原版游戏截图（`gui_ref/`，版权原因不入库），配色暂用夜樱深紫 + 金（`#16121f` 底 / `#d8b46a` 金）。座次色沿用 CLI：黄/青/紫/红。

| 图 | 界面 | 要点 |
|---|---|---|
| 01_main_menu | 主菜单 | 卡组构筑 / 本地热坐 / 联机对战 三入口；左下本地玩家卡；底部免责声明 |
| 02_deck_list | 阵容（卡组列表） | 横向滚动卡组列，每列 4 式神菱形竖列（原版阵容页版式）；标准卡组亮蓝描边；码/名/删 操作钮 |
| 03_deck_editor | 卡组编辑 | 左：版本包→式神二级目录+搜索；中：该式神 8 主卡+协战牌网格（n/2 计数，不强制）；右：4 式神当前带卡；顶部卡组码复制、环境选择、标准校验标记 |
| 04_vs_splash | 对阵展示 | 敌方 4 卡左上倾斜+头像右上，我方 4 卡右下+头像左下，中央 VS、环境与先后手 |
| 05_battle | 对局主界面 | 四角头像+生命+鬼火；双方 4 式神立绘卡弧形排列、战斗区卡前移；敌方手牌背右上；我方手牌右下扇形；中央回合横幅（阶段/升级计数/计时）；右缘牌库+圆形结束回合钮；左缘"录"=结算记录开关（点击展开覆盖面板，非常驻栏） |
| 06_mulligan | 起始调度 | 暗化背景中央 4 张大卡；左上先后手菱形徽标+替换计数+座次；右上对方手牌背+确认钮；选中卡金描边+"替换"标记；底部倒计时（超时按当前选择确认） |
| 07_online_lobby | 联机大厅/房间 | 服务器地址+玩家名+连接预检；卡组下拉（标准√）；房码可自定义 6 位；房间内双方卡片区、准备/取消准备、15s 自动准备说明 |

交互基调（与 gui-plan.md 一致）：拖拽出击、点击出牌、点击目标选择（1 起编号改可视化点选）、点击查看卡牌/式神详情、结算细节走"录"开关面板+重要事件中央浮字。

## 4. 待确认问题

1. **配色**：初稿用夜樱深紫+金（近原版色调），是否沿用，还是走自己的主题色？
2. **结算记录**：初稿定为左缘"录"钮开关式覆盖面板（不占常驻布局），可否？需要默认展开吗？
3. **主菜单**：是否加"图鉴/式神录"入口（看全卡与描述，独立于构筑）？
4. **阵容菱形版式**：初期无头像/立绘资源，菱形与对局立绘卡都用纯色+文字占位，之后由 BWPDIY render 合成卡面替换——占位样式可否？
5. **对局界面信息密度**：初稿未画幻境队列/灵咒/倒计时等状态区——计划做在式神卡的角标与牌手头像旁的小图标列（悬停展开），这个方向可否？
