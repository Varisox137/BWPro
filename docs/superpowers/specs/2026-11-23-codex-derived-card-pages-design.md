# 式神录衍生内容分页设计

## 目标

在式神录的单个式神卡牌列表中，将常规卡牌与衍生内容分区连续分页，并提供直接跳转按钮；所有内容保持进入列表时一次预载。

## 内容与顺序

- 常规组：式神本体 + `buildable_cards` 返回的可构筑卡牌，沿用现有顺序。
- 衍生组：当前数据环境 `edb` 中，所属该式神的全部 `token` 卡牌，以及 `kind != shikigami` 且 id 前缀属于该式神的召唤、变形、替换实体，统一按 id 升序。
- 未发布内容继续由环境解析排除。雪女的衍生组因此包含雪球与冰墙；三目的衍生组独立占第 3–6 页。
- 两组分别按每页 5 项切分，再拼接页表。常规组末页留白，衍生组从新页开始；没有衍生组时不添加空页。

## 导航

页码栏从左到右为：

```text
查看主要卡牌  ‹  第 x/y 页  ›  查看衍生卡牌
```

- 两个区域按钮仅在该式神具有衍生内容时可见，样式沿用现有翻页小按钮。
- “查看主要卡牌”仅在当前页属于衍生区时可用，点击跳转第 1 页。
- “查看衍生卡牌”仅在当前页属于常规区时可用，点击跳转首个衍生页。
- 普通前后翻页保持逐项移动；没有衍生内容时页码栏维持现状。

## 渲染与交互

- 进入列表时仍为常规组与衍生组的全部真实控件各创建一次；翻页只切换布局与可见性，不重新合成卡图。
- 衍生项复用现有左键查看详情、右键异画/牌框切换功能。
- 各页卡图等高，按卡框中线对齐五个等距槽位；末页保留相同槽位，不再创建空白占位控件，避免覆盖返回页卡图。

## 验证

- 无衍生内容的式神不增加页数或区域按钮。
- 常规组末页不得混入衍生项；衍生组首页及页数正确，组内按 id 排序。
- 区域按钮的可见性、可用性、跳转目标和普通翻页状态随页正确更新。
- 衍生项详情与外观对话框使用当前 `edb`；翻页不增加加载事件或重建控件。
- 往返末页后无遗留可见占位控件。
