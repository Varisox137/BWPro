# GUI 详情尺寸、右键入口与额外状态精简设计

日期：2026-10-31

## 目标

统一构筑、式神录和对局详情的卡图尺寸与真实机制框宽度，优化对局边缘布局，并让所有详情可在只读状态下通过右键打开。精简式神额外状态，避免暴露不必要的内部数值。

## 卡图与机制框尺寸

- 三种详情统一请求原生 `height=512` 卡图，式神主卡与形态同尺寸；弹窗高度同步增加。
- 机制框保持 `chars_per_line=12`。
- 先测量 `font_scale=1.0` 的原生机制框宽，再以“卡图实际宽度 / 原生机制框宽”计算缩放比例，最大为 1.0；用所得 `font_scale` 原生重绘，不做各向异性拉伸。
- 卡图控件与机制栏容器只承接实际渲染尺寸，真实宽度一致。机制区最大高度同为 512，减少不必要的纵向滚动；内容超出时保留滚动作为兜底。
- 暴露只读卡图宽度属性，替代详情模块读取 `CardWidget._display_art` 的私有路径。

## 对局边缘布局

牌手图元与对局记录按钮左移 12px，手牌区和结束回合按钮右移 12px。允许少量场景外裁切，保持现有半高手牌、间距、式神避让和主题布局，不改变顶部 chrome 边距。

## 右键只读详情

所有查看详情入口统一为右键单击，包括构筑、式神录、普通对局、调度、pending choice、交接和终局。

- 左键只负责出击、选牌、调度、目标选择与 pending 作答。
- 右键只打开详情，不触发选中、拖拽、目标选择或作答。
- 任何阶段均允许右键查看，不再以 `_inputs_open()` 拦截只读入口。
- 敌方暗手牌仍不可查看内容；秘密 delayed 继续按 viewer 脱敏。
- `CardWidget` 增加独立右键信号，左键 `clicked` 的既有选择语义不变。

## 额外状态精简

式神详情第三列仅保留卡牌赋予的 delayed 与灵咒：

- delayed 显示来源、触发类型、次数与可见目标；
- 灵咒显示名称、来源和效果文本，不展开力量/生命修饰数值；
- 移除护甲/破甲、能量、临时/永久/动态修正、力量覆写、普通与攻击关键字、保留护甲/破甲、免疫、眩晕、濒死、离场、气绝与倒计时等内部状态。

第四列机制说明继续按原文顺序提取，不因状态精简引入新的秘密信息。

## 验证

覆盖三类详情的 512 高度、真实宽度一致、font_scale 上限、机制滚动兜底、边缘坐标、各阶段右键详情、左键操作不变、暗手牌与秘密过滤、额外状态仅 delayed/灵咒，以及公开 art_width 属性。最后运行相关 GUI 测试与默认 `-n 4` 全量测试。
