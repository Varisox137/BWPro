# GUI 五卡布局与联机入口调整设计

## 目标

修复卡组构筑、式神录五卡浏览时的卡面裁切与对齐问题，简化式神录卡牌列表，并调整联机连接页和大厅的交互。

## 卡牌与式神录

- 构筑和式神录共用五卡等宽布局：每列宽度一致，完整页的外缘左右对齐；不足五张时按相同列宽左对齐。
- 移除卡牌行末尾额外拉伸及会迫使卡面裁切的固定最小宽度。卡图根据实际列宽调用 BWPDIY 原生尺寸渲染，保持长宽比，不以拉伸图片填满列宽。
- 式神录树减少式神名前缩进；选中式神整行使用明显的浅蓝底，并保持文字与主题背景的对比度。
- 式神录卡牌列表移除上方立绘、身材和基础能力区域，只保留返回栏、式神名、五卡浏览区与翻页栏。

## 联机流程

- 连接页不再显示卡组选择，仅要求服务器地址和玩家名。
- 卡组选择器移入大厅；创建房间或首次加入房间前必须选择标准卡组，令牌重连不重复校验卡组。
- 连接预检或建立 WebSocket 失败时，使用应用内小型警告弹窗显示原因，不再占用连接页常驻错误行。
- 主窗口“退出对局”按钮只在联机实际对局页显示；连接页和大厅不显示，热坐行为不变。

## 对局显示与初始化

- 双方牌库数量文本移至对应牌库卡背组右侧，不再压在卡背上方或下方；为文本保留独立空间，不遮挡结束回合按钮。
- 结束回合按钮补充明确的禁用态样式：不可操作时降低对比度并改变边框、背景与文字颜色，可用态维持现有金色强调。
- 根因已复现：热坐 `start_hotseat` 和 `start_game` 默认固定 `seed=42`，导致相同卡组每次起手一致；联机房间已使用随机种子。热坐未显式传种子时改为每局生成随机种子，核心 `new_game` 与测试显式种子的确定性不变。

## 测试与验收

- 在常见窗口宽度下验证五张卡均完整位于卡牌区域内，列宽相等、左右边界对齐，末页保持左对齐。
- 验证式神录列表不再创建上方信息区，树选中样式包含浅蓝底。
- 验证无卡组也能连接进入大厅，无卡组不能建房或首次加入；连接失败调用警告弹窗。
- 验证联机连接页、大厅隐藏“退出对局”，对局页显示。
- 验证双方牌库文本位于卡背组右侧且不超出场景，结束回合具有独立禁用态样式。
- 连续两次未显式传种子的热坐开局使用不同种子；显式种子仍精确传给 `new_game`。
- 运行相关 GUI 测试、全量 pytest 与 `db.validate`。
