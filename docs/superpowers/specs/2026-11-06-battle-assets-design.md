# 对局首批美术素材接入设计

日期：2026-11-06

## 目标

接入气绝、运势、回合、结束回合、胜负、卡背与黑色骰子素材；热坐和联机表现一致，动画不阻塞合法操作，不改变规则结算。

## 路径与资源

- 沿用 BWPDIY 当前资源命名，不恢复已删除的 `masks/`、旧 `signs/`、`reinforce_*` 等兼容路径。
- 新增 BWPro 本地 UI 资源加载与 QPixmap 缓存；冻结包从 `_MEIPASS/assets` 读取，源码从项目根读取。
- `dice/black_open.png` 展开图按实际边界裁取六个 128×128 面：1=(171,171)、2=(171,0)、3=(0,171)、4=(340,171)、5=(171,340)、6=(340,0)；六点样式参考 `black_6.png`。

## 视觉事件

- 引擎 timeline 增加仅供 GUI 的结构化事件：式神气绝、运势判定、运势重投；包含座位、骰点和结果等必要字段。
- 热坐按 timeline 顺序播放；联机由服务器原样下发公开视觉事件。文字日志过滤规则不变，视觉事件不进入对局记录。
- 气绝：在对应式神位置渐现渐隐 `defeated_light.png`，动画结束前不绘制复活倒计时，随后恢复正常小卡状态。
- 运势：在来源式神位置显示骰子点数；无来源式神时使用判定牌手位置。成功、失败、重投分别叠加 `dice_successful.png`、`dice_unsuccessful.png`、`dice_reroll.png`，统一渐现渐隐。
- 回合：按当前视角显示 `your_turn_*` 或 `opponent_turn_*`；文件名表示字色，浅色主题用 dark 文件、深色主题用 light 文件。

## 常驻交互与设置

- 结束回合按钮保留原生 QPushButton 和既有尺寸/命中区域，以 `end_turn_button.png` 绘制可用状态，以 `opponent_turn_button.png` 绘制对方回合不可用状态，不改变合法性检查。
- 终局按本地视角显示 `won.png` 或 `lost.png`；平局及房间终止保留文字提示。
- 设置页增加己方、敌方卡背下拉框，只列出 `cardbacks/` 中已命名 PNG，默认均为「月明风清」，保存到 `$HOME/.bwpro/gui.json`。
- 敌方未展示手牌、双方牌库和用牌动画的未翻面阶段使用所选卡背；已展示手牌仍显示真实卡面。

## 验证

- 单元测试覆盖骰子六面裁剪、命名卡背过滤与默认配置持久化、主题资源选择、结构化事件播放和气绝倒计时延迟。
- 热坐与联机均验证视觉事件不进入文字记录、不阻塞输入、切换视角和离开对局时正确清理。
- 真实离屏渲染抽查六种骰面、两种回合字样、卡背、按钮和胜负图；最后运行全量 pytest 与 `git diff --check`。
