# GUI 交互与动画设计

## 目标

修正卡图比例与操作反馈，解除记录播放对合法操作的阻塞，并为式神移动和双方用牌增加简单、非阻塞的线性动画。

## 卡图比例

- 调度、手牌、详情等大卡按固定高度调用合成管线，显示端只做等比缩放，禁止各向异性拉伸。
- 缺图回退与真实卡图遵守同一比例；测试覆盖显示尺寸与关键图像内容。

## 操作着色

- 可出击式神显示黄框。
- 可用但所有合法方式都需耗鬼火的卡牌显示黄框；存在合法零鬼火方式的卡牌显示蓝框，零鬼火包括瞬发名额、自身不耗鬼火及增强/其他效果。
- 多择牌优先显示绿框，不再按黄/蓝区分。
- 不合法牌不显示操作框；合法性与颜色均读取当前 `usage_options`，不另建规则口径。

## 后台记录与阶段提示

- 本地热坐和联机均允许在 timeline 播放期间继续合法操作，状态立即刷新，记录继续后台播放；待处理选择、交接、终局和联机等待响应等既有门控保持不变。
- `调度阶段 / 升级阶段 / 主要阶段` 移到“玩家xx 回合xx”右侧，使用较小字号，不再居中覆盖场况。

## 调度交接

第三次初始调度后拆成两个连续确认：

1. “调度完毕请确认”：保留当前手牌供查看，不切换视角。
2. 常规“准备移交”：确认后清空手牌并切换到另一位玩家。

## 非阻塞动画

- 式神进入战斗区、移回准备区时，在原位置与目标位置之间进行短时线性移动；初次渲染与视角切换不播放。
- 双方所有用牌均播放：从原手牌位置离开，翻转后在画面左侧以大卡短暂停留，再淡出移除；不阻断后续指令。
- timeline 用牌条目附公开 `uid/card_id/player` 元数据，动画不解析中文日志；不改变卡牌使用合法性或隐私规则。
- 同一图元的新动画取代旧动画，避免位置与透明度残留；拖拽、交接、重开对局时清理对应动画。

## 测试

- 覆盖等比显示、黄/蓝/绿着色、后台可操作、阶段位置与两段交接。
- 覆盖移动动画终点、双方用牌元数据与动画清理，并确认动画期间可继续操作。
- 运行 GUI 相关测试及默认 `-n 4` 全量测试。
