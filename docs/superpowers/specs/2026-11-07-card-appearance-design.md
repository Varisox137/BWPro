# 卡牌牌框切换与选择弹窗统一设计

## 目标

在式神录的式神卡牌详情页提供牌框切换：左键打开外观弹窗，右键继续查看详情。外观选择按卡牌 id 保存在本机，并应用于构筑、式神录、对局和详情中的大卡图。异画仅预留数据结构，本轮不开放异画选择。

## 外观偏好

新增 `client/gui/card_appearance.py`，使用 `~/.bwpro/card_appearance.json` 保存稀疏偏好。文件只记录非常规牌框；常规牌框通过删除对应条目表示。按卡牌 id 关联，不区分平衡性版本，不修改引擎数据或 `library/` 配置。

牌框枚举为 `norm`（常规）、`blue`（琉璃）、`black`（墨染）、`red`（百炼）。异画字段只保留默认原画的内部表示，不提供界面或额外资源发现逻辑。读取时忽略损坏或非法条目，写入采用同目录临时文件替换；读取失败回退默认外观，保存失败向用户提示。

`client/gui/cardart.py` 在生成大卡图负载前应用本机牌框偏好。现有负载、布局与缓存键自然包含实际牌框，不另建缓存目录。对局式神小卡保持原行为。

启动预热只合成每张卡当前选用的原画/牌框，不枚举四种牌框，缓存任务总量不因本功能扩大。预热 manifest 的逐卡内容指纹包含当前外观；外观变化后仅新外观需要实际合成，其他条目继续复用内容寻址缓存。

## 外观弹窗与式神录交互

新增外观对话框：顶部为四个牌框按钮，中央为当前牌框下的原画大卡，底部为确认与取消按钮。点击牌框只更新预览，确认后才保存；取消不改变既有偏好。当前没有异画时只显示原画，不显示空白异画选择区。

式神录卡牌列表的 `CardWidget.clicked` 连接外观对话框，`detail_clicked` 继续连接单卡详情。确认后重新渲染当前页，翻页、切换环境及其他界面后续渲染均读取同一偏好。

## 选择弹窗统一调整

`CardChoiceView` 与新外观弹窗采用一致的紧凑纵向间距：按钮贴近放大卡图下缘，对话框按卡图和按钮的实际高度完整展开，不为正常内容提供纵向滚动。移除黄色选中光框；选中反馈保留卡图居中放大、其他候选变暗和候选下方确认按钮。卡图继续保持宽高比。

## 验证

定向测试覆盖：

- 偏好文件的稀疏保存、默认删除、非法输入回退与原子写入路径；
- 牌框偏好进入大卡图负载和布局，且运行时覆盖仍有效；
- 式神录左键打开外观、右键打开详情，确认后刷新当前页；
- 牌框切换只在确认后保存，取消无副作用；
- 选择视图不再创建黄色光框，放大卡图与按钮使用紧凑间距。
